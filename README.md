\# 🕵️ AI QUEST — Intelligent Detective Game



An interactive AI-powered detective game where players investigate cases, analyze clues, interact with characters, and solve mysteries.



\## 🎮 About the Game



AI QUEST combines detective gameplay with artificial intelligence concepts to create an interactive mystery-solving experience.



Players take on the role of a detective and progress through different investigations by:



\- 🔎 Examining clues

\- 🧩 Solving mysteries

\- 💬 Interacting with characters

\- 🤖 Using AI-powered analysis

\- 📊 Exploring investigative information

\- 🕵️ Making decisions that influence the investigation



\## ✨ Features



\- Interactive detective gameplay

\- AI-based threat and clue analysis

\- Character interaction system

\- Mystery and investigation mechanics

\- Data-driven game components

\- Visual elements and graphical interface

\- Character-based storytelling

\- Windows desktop application



\## 🤖 AI Components



The project uses machine-learning techniques for intelligent analysis, including:



\- TF-IDF text feature extraction

\- Scikit-learn based analysis

\- Threat detection

\- Text classification and similarity analysis
