## 🎯 Project Overview

**AI QUEST — Intelligent Detective Game** is an interactive desktop-based detective game designed to combine **artificial intelligence, machine learning, game mechanics, storytelling, and data analytics** into a single application.

The player takes the role of a detective and investigates a series of digital cases. Each investigation requires the player to examine evidence, interpret clues, interact with characters, review AI-generated threat analysis, and make the final decision about whether the evidence is **SAFE** or **DANGEROUS**.

The project transforms machine-learning concepts into an interactive game environment, making AI-based classification and decision-making more engaging and understandable.

---

## 🕵️ The Concept

The player begins by selecting a detective character and entering a detective name.

The investigation then progresses through multiple levels. Each case contains evidence that must be investigated before the player makes a final decision.

The AI system independently analyzes the evidence using multiple machine-learning models:

- 🤖 Naive Bayes
- 📈 Logistic Regression
- 🌲 Random Forest

The predictions generated by the models are combined to produce an **AI consensus**.

The player then makes the final detective decision.

This creates a comparison between:

**AI Decision → Human Decision → Final Investigation Result**

# 🤖 Artificial Intelligence & Machine Learning

The core intelligence of AI QUEST is based on a text-classification pipeline.

Evidence and investigation-related text are transformed into machine-readable features and analyzed using multiple classification algorithms.

### Machine-Learning Models

| Model | Purpose |
|---|---|
| 🧪 Naive Bayes | Probabilistic text classification |
| 📈 Logistic Regression | Binary classification and probability estimation |
| 🌲 Random Forest | Ensemble-based classification and robust prediction |

Using three different models allows the application to compare predictions rather than depending on a single algorithm.

---

## 🔬 AI Analysis Pipeline

The AI component follows a text-classification workflow:

### 1. Input

Investigation evidence and related text are provided to the system.

### 2. Text Processing

The text is prepared for machine-learning analysis.

### 3. Feature Extraction

**TF-IDF (Term Frequency–Inverse Document Frequency)** is used to convert textual information into numerical features.

### 4. Model Prediction

The processed features are passed through:

- Naive Bayes
- Logistic Regression
- Random Forest

### 5. Confidence Analysis

Each model produces a prediction and associated confidence value.

### 6. AI Consensus

The model predictions are compared.

When the models agree, the application uses the agreement as an AI consensus signal.

### 7. Detective Decision

The player reviews the evidence and AI analysis before selecting:

- 🔴 **DANGEROUS**
- 🟢 **SAFE**

This allows the project to demonstrate the relationship between automated AI analysis and human decision-making.
