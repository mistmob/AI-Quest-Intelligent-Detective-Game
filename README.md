## 🎮 About the Project

**AI QUEST — Intelligent Detective Game** is a major project that combines an interactive detective experience with **Artificial Intelligence, Machine Learning, data analysis, and visualization**.

The player takes on the role of a detective and progresses through investigations by examining clues, interacting with characters, analyzing evidence, and making decisions.

The project transforms machine-learning concepts into an interactive application where the player can experience AI-assisted investigation rather than simply viewing model outputs in a conventional interface.

- 🕵️ Interactive detective gameplay

- 🤖 AI-powered threat analysis

## 🎮 Gameplay

AI QUEST follows a step-by-step investigation process where the player acts as a detective and uses both **personal judgment and AI-assisted analysis** to solve cases.

### 🕵️ 1. Choose Your Detective

The player begins by selecting a detective character and entering their detective identity.

### 🔎 2. Investigate the Case

The detective receives an investigation containing relevant case information and evidence.

### 🧩 3. Examine the Evidence

Players examine the available clues and information before making their decision.

### 🤖 4. Analyze the Evidence with AI

The evidence is processed through the machine-learning pipeline to determine its potential threat classification.

### 🧠 5. Compare AI Models

The system analyzes the evidence using:

- 🧪 Naive Bayes
- 📐 Logistic Regression
- 🌲 Random Forest

### 🎯 6. Make the Final Decision

The detective makes the final classification:

- 🟢 **SAFE**
- 🔴 **DANGEROUS**

### 🏆 7. Receive the Result

The player's decision is evaluated and the game updates the detective's score, accuracy, mission progress, and investigation results.

## 🤖 Artificial Intelligence

The AI component is designed to analyze textual investigative evidence using machine-learning techniques.

The overall pipeline is:

**Evidence → Text Processing → TF-IDF → Machine Learning Models → Model Comparison → AI Consensus → Threat Classification**

## 📝 TF-IDF Text Analysis

**Term Frequency–Inverse Document Frequency (TF-IDF)** is used to convert textual evidence into numerical feature representations that can be processed by machine-learning algorithms.

This allows the system to identify patterns in investigative text and use those patterns for classification.

## 🧠 Machine Learning Models

### 🧪 Naive Bayes

A probabilistic machine-learning algorithm used for text classification.

### 📐 Logistic Regression

A classification algorithm used to determine whether evidence belongs to a particular threat category.

### 🌲 Random Forest

An ensemble learning algorithm that combines multiple decision trees to produce a classification result.

## 🗳️ AI Consensus

AI QUEST compares the predictions generated by the three machine-learning models.

The individual predictions are combined to provide an overall AI-assisted classification.

This allows the application to demonstrate **multi-model decision support** rather than relying on a single machine-learning model.

## 🕵️ Human + AI Investigation

AI QUEST follows a **human-in-the-loop** approach.

The AI provides analytical assistance, while the detective remains responsible for interpreting the evidence and making the final decision.

**AI Analysis + Evidence + Detective Judgment = Final Investigation**
